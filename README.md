# ⚖️ JurisGuide – Report, Track, Resolve! 🎓
🚀 Empowering MUET Students to Voice Concerns & Get Quick Resolutions!

## 🛠️ Built With
🐘 PHP | 🛢️ MySQL | 🎨 HTML/CSS | ⚡ JavaScript | 💎 Bootstrap 5

## 🌟 What is JurisGuide?
Students can report issues, track status, rate resolutions, and give feedback. Admin can manage complaints with complete workflow.

**Students can:**
✔️ Submit complaints (7 categories)
✔️ Track status in real-time
✔️ Rate resolution (1-5 stars)
✔️ Delete pending complaints

**Admin can:**
✔️ View all complaints
✔️ Update status (Start → Resolve → Close)
✔️ Search complaints
✔️ Review unsatisfied complaints

## 📋 Complaint Categories
- Any kind of Harassment
- Clash between students
- Hostel issues
- Misbehave
- Attendance issues
- Accident
- Complaint against cafeterias

## 🚀 How It Works?
1. **Sign Up** → Use @muet.edu.pk email
2. **Submit** → Choose category, write complaint
3. **Admin** → Reviews & updates status
4. **Student** → Rates & confirms satisfaction

## 🛠️ Installation
1. Copy folder to `C:\xampp\htdocs\jurisguide`
2. Start Apache & MySQL in XAMPP
3. Create database `uni_complaints` in phpMyAdmin
4. Open browser: `http://localhost:8080/jurisguide`

## 🔑 Login Credentials
**Admin:** `admin` / `admin123`
**Student:** Signup with @muet.edu.pk email
